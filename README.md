## 모델 구조

- **Backbone**: CLIP ViT-L/14 (`openai/clip-vit-large-patch14`)
- **Vision**: GK2A 위성 이미지 6장 각각 인코딩 후 concat
- **Text**: ASOS 수치 텍스트 인코딩
- **Head**: `[img_feat × 6 + txt_feat]` → Linear(1024) → Linear(256) → 7클래스

### 핵심: CLIP 전체 파라미터 Unfreeze

CLIP 인코더를 freeze하지 않고 **전체 파라미터를 학습**시킴.

```python
for param in clip_model.parameters():
    param.requires_grad = True
```

| 구분 | 파라미터 수 | lr |
|------|------------|-----|
| CLIP 전체 (Vision + Text encoder) | ~427M | 1e-5 |
| FC 분류 헤드 | ~1.5M | 1e-3 |

일반적인 CLIP 파인튜닝은 헤드만 학습하거나 마지막 몇 레이어만 unfreeze하는 방식을 사용하지만, 본 실험에서는 위성 이미지라는 도메인 특수성(일반 이미지와 분포 차이가 큼)을 고려해 전체 인코더를 학습함. CLIP 인코더에는 낮은 lr(1e-5)을 적용해 사전학습 지식이 과도하게 손실되지 않도록 함.
